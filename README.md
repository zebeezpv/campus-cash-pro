# Campus Cash Pro

A mobile-friendly student budgeting web app.

## Main features

- Editable monthly income
- Automatic expense totals
- Automatic remaining-balance calculation
- Additional income and expense transactions
- Expense reasons and emojis
- Savings goal and savings contributions
- Monthly category budgets
- CSV export
- JSON backup and restore
- Offline support
- Local device storage

## Deploying

This is a static site. Deploy the repository on Vercel with:

- Application preset: Other
- Root directory: ./
- No build command
- No output directory
