# Campus Cash Pro — Updated Version

This version is a standalone Progressive Web App. It uses normal HTML, CSS and JavaScript, so it works on GitHub Pages, Vercel or Netlify without a React build process or backend.

## Features adapted from the supplied React code

- Transaction search
- Previous/next month controls
- Add and edit transactions
- Single and bulk deletion with confirmation
- Select all / deselect all
- Custom categories
- Category emoji, colour and monthly budget
- Detailed monthly budget page
- Budget progress and over-budget warnings
- Responsive mobile layout

## Existing Campus Cash features retained

- Income and expense tracking in ZAR
- Reasons and emojis
- Receipt images
- Savings goals
- Recurring monthly items
- Payday allowance calculator
- Spending insights
- CSV export
- JSON backup/import
- Dark mode
- Local PIN
- Offline PWA support

## Important

Data is stored in the browser with localStorage. It will not automatically sync between devices. Use the JSON backup feature regularly.
